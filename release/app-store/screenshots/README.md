# App Store screenshots

These are unframed captures from the release build with a clean 9:41 status bar. They contain no debug overlays, development tools, or promotional text. Both the Vintage burgundy table and Classic green table are represented on iPhone and iPad.

## Suggested upload order

### iPhone 6.5-inch display

The files are numbered in upload order:

1. `iphone-6.5/01-vintage-opening-portrait.jpg` — clean Vintage opening deal, portrait (1284 × 2778)
2. `iphone-6.5/02-classic-opening-portrait.jpg` — clean Classic opening deal, portrait (1284 × 2778)
3. `iphone-6.5/03-classic-draw3-midgame-portrait.jpg` — Classic Draw 3 mid-game, with the three-card waste fan visible (1284 × 2778)
4. `iphone-6.5/04-vintage-midgame-landscape.jpg` — Vintage mid-game, showing the wide-table layout and side controls (2778 × 1284)
5. `iphone-6.5/05-classic-draw3-midgame-landscape.jpg` — Classic Draw 3 mid-game, showing the wide-table layout, three-card waste fan, and side controls (2778 × 1284)
6. `iphone-6.5/06-settings-portrait.jpg` — style selector, settings, and local records (1284 × 2778)

The two clean opening deals lead with the app's most polished, spacious views and establish both card styles. Both styles then appear in landscape because the side control rail and wide-table layout materially change the experience. Settings appears last so gameplay remains the focus of the gallery.
