# Better Solitaire ♠️

Klondike solitaire the way it should be. **Free forever. No ads. No in-app purchases. Just cards.**

First in the **"Better"** series: better versions of popular App Store apps that
people actually use, but which aren't free, or are ruined by ads and IAP.

Play it: open `www/index.html` in any browser (works great on a phone), or
serve the folder (`cd www && python3 -m http.server`) to get PWA install +
offline caching. It's also wrapped with [Capacitor](https://capacitorjs.com)
for a native iOS build.

## Features

- **Full Klondike** — draw-1 or draw-3, unlimited stock recycles, drag *and*
  tap-to-play (tap a card and it flies to the smartest legal spot)
- **Adjustable deal mix** — choose five steps from fully Random to fully
  Winnable; verified deals are certified under both draw-1 and draw-3
- **Daily streak 🔥** — win at least one game a day to keep it alive
- **Streak freezes ❄️** — every 10 wins earns a freeze (max 3);
  a missed day is quietly covered by a freeze at your next win
- **Move counter & timer**, personal bests (fastest win, fewest moves), win rate
- **Undo with a gentle cost** — your first undo each game is free; after that,
  each undo counts as a move (the move count never goes down)
- **Hints** (`h`), space bar to draw, ⌘Z to undo
- **Auto-finish** — automatically clears the forced endgame when enabled
- **Win celebration** — the classic trailing card cascade (an homage to the
  Windows original), painted on canvas, followed by a stats card
- **Deal animation, 3D card flips, restart-same-deal**, and full persistence —
  close the tab mid-game and it resumes exactly where you left off
- **Recorded card-shuffle sound** on fresh deals, with a persistent mute setting
- Respects `prefers-reduced-motion`

## Design

A midnight card room: deep pine felt `#0F2E25`, warm paper cards `#FAF5E9`,
carmine `#BF3B33` and ink `#26282E` suits, brass `#D9A648` reserved for the
streak flame, hints, and celebration. Card faces are typographic — real pip
layouts, Palatino/Iowan serif indices — in the playing-card tradition.

## Architecture

The shipped game has zero third-party runtime dependencies. Stable seams keep
copy, card-placement rules, persistence, and generated deals separate from the
DOM orchestration.

```
  www/            # Capacitor webDir — the shipped web app
  index.html    # markup, CSS, and browser orchestration
  copy.js       # editable interface language and dynamic copy helpers
  game-rules.js # pure foundation/tableau placement rules
  persistence.js # validated, versioned local storage with recovery copies
  deal-engine.js # deterministic seeded shuffle + winnable deal selection
  winnable-deals.js # generated, compact seed index shipped with the app
  manifest.json # PWA: installable, standalone, portrait
  sw.js         # service worker: offline shell caching
  icons/        # PWA + apple-touch icons (brass ♠ on felt)
assets/         # 1024²/2732² icon + splash sources; build-icons.mjs regenerates all art
capacitor.config.json   # appId dev.ehutt.solitaire, webDir www
ios/            # generated by `npx cap add ios` (needs full Xcode)
scripts/        # corpus generator, replay engine, and solver build helper
vendor/         # pinned GPLv2 Solvitaire source used only by offline tooling
```

- `www/index.html` — markup, CSS, and browser orchestration
  - State: `cards[52]` + piles `{stock, waste, f[4], t[7]}`
  - Rendering: absolutely-positioned card divs moved with `transform`
    (layout is a pure function of state + board size)
  - Undo: full-state snapshots (id arrays + face flags), capped at 400
  - Persistence: `localStorage` (`patience.v1.game` / `.stats` / `.settings` —
    key names kept stable across the rename so no one loses a streak)
  - Streak math: local day numbers, freezes consumed at win-reconciliation

See [DEVELOPMENT.md](DEVELOPMENT.md) for local checks, CI, the browser/device
matrix, safe-refactor rules, and recommended `main` branch protection.

## Winnable deal corpus

Winnable deals are backed by `data/winnable-deals.v1.json`. Every entry contains
separate draw-1 and draw-3 move certificates, and the test suite replays every
certificate through the repository's Klondike rule engine. Only the compact
seed list in `www/winnable-deals.js` ships at runtime.

The independently pinned Solvitaire source is committed under
`vendor/solvitaire` with its GPLv2 license and macOS portability changes. It is
an offline executable and is not included in the shipped app. Build it once
with CMake and Boost installed:

```bash
npm run solver:build
```

The corpus generator automatically finds that repository-local binary.
Generate a new corpus with:

```bash
npm run deals:generate -- \
  --count 1000 --require-external --workers 8
```

Safely grow an existing corpus by passing the desired total:

```bash
npm run deals:generate -- \
  --count 2000 --append --require-external --workers 8
```

An existing internally certified corpus can be independently checked, with
solver disagreements quarantined and automatically replaced:

```bash
npm run deals:generate -- \
  --count 1000 --append --recertify --require-external --workers 8
```

The pipeline first solves and replays each deal itself, then optionally asks
[Solvitaire](https://github.com/thecharlieblake/Solvitaire) for an independent
classification. A timeout is treated as unknown and discarded. Seeds, shuffle
version, rules version, solver metrics, and both certificates are retained so
future changes can be audited. Append mode validates corpus compatibility and
seed uniqueness, preserves existing certificates, and resumes after the highest
previously accepted seed. Candidate batches are evaluated in parallel but
committed in seed order, and corpus/index files are replaced only after the
requested total has been completed.

## Road to the App Store

**Phase A — done ✅** (no Xcode required)

- [x] PWA pass — `manifest.json` + service worker (installable, offline)
- [x] Capacitor wrap — WKWebView shell, `dev.ehutt.solitaire`, no game-code changes
- [x] Haptics — `@capacitor/haptics` fires on card drops / scoring / win (no-op on web)
- [x] App icon + splash — brass ♠ on felt, all sizes generated from `assets/`

**Phase B — needs full Xcode.app + CocoaPods**

```bash
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
sudo gem install cocoapods
npx cap add ios
npm run assets        # capacitor-assets: iOS icons + splash from assets/
npm run ios           # cap sync + open in Xcode → run in the Simulator
```

**Phase C — needs Apple Developer Program ($99/yr)**

- Signing + bundle id, App Store Connect listing, screenshots, TestFlight, submit
- Optional: Game Center leaderboards for streak / best time

Price: **free**, no IAP, no ads. That's the whole point.
